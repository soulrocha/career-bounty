# Segurança

## Canal de reporte

Reporte vulnerabilidades de forma privada, pelo recurso de aviso de segurança do GitHub
(aba Security do repositório, "Report a vulnerability"). Não abra issue pública com detalhes
de uma falha e nunca anexe dados pessoais reais ao relato.

## Política de divulgação

- Confirmamos o recebimento em até 7 dias.
- Buscamos corrigir falhas confirmadas em até 90 dias.
- A divulgação pública acontece depois da correção, ou ao fim de 90 dias, o que vier primeiro,
  com crédito a quem reportou, se desejado.

## Escopo

Vazamento de dado pessoal por commit, execução de comando a partir de conteúdo externo,
acesso não autenticado ao painel local e qualquer caminho que contorne o padrão de não
enviar candidatura sem confirmação.
